# Yavka

**ЯВКА — Координатор встреч**

Браузерная beta для небольших компаний: предложить встречу → пригласить друзей → проголосовать → подтвердить план → сообщить статус → завершить встречу → сохранить воспоминания.

**Договорились. Встретились. Сохранили.**

## Запуск

Требуется Node.js 20.19+ или 22.12+ (проверено на Node.js 24).

```bash
cd /workspace/Yavka
npm install
npm run dev
```

Vite запускает сервер на порту 5173. Для повторной установки по сохранённому lockfile используйте `npm ci`.

```bash
npm run build       # Production-сборка в dist/
npm run preview     # Проверить production-сборку, порт 4173
npm test            # Проверки бизнес-правил и экспорта календаря
npm run test:e2e    # Полный сценарий в Chromium, desktop и mobile
```

Браузерные тесты используют системный Chromium, если он установлен. Иначе установите его через `npx playwright install chromium`. Путь к другому установленному Chromium можно задать через `PLAYWRIGHT_CHROMIUM_EXECUTABLE`. Для размещения production-сборки настройте возврат `index.html` для маршрутов `/join/*` и `/meetings/*` (SPA fallback).

## Что работает

- Главная страница с предстоящими встречами и историей, создание встречи с несколькими вариантами времени и места.
- Приглашение по ссылке и QR, присоединение по имени без регистрации, выбор нескольких вариантов и подсчёт голосов.
- Итоговый план, выбор «Буду / Не смогу / Не уверен». Действия организатора отделены от действий гостей.
- **После изменения даты, времени, места или адреса все подтверждения участия сбрасываются.** Статусы прибытия и минуты опоздания также сбрасываются. Повторное сохранение неизменённого плана сохраняет ответы.
- Статусы «Ещё дома», «Выхожу», «Задерживаюсь» с выбором минут, «Прибыл», общий список «Все собираются».
- Выгрузка `.ics` без внешнего API. Время календаря локальное, длительность события по умолчанию 90 минут.
- Завершение, необязательные фотографии и заметка, история с подробностями. До 6 фото JPG/PNG/WebP по 2 МБ; изображения уменьшаются перед локальным сохранением. При нехватке места выводится сообщение, существующие данные сохраняются.
- Toast-уведомления, адаптивный интерфейс, верхняя навигация на компьютере и нижняя на телефоне.

## Демонстрация для жюри

При первом запуске появляется «Кофе после пар»: Сардор, Нуржигит, Наталья, Данияр и Камила. Дата — завтра, время первого варианта — 18:30, место — Surf Coffee. У четырёх друзей уже есть голоса.

1. Откройте встречу, сохраните ответы Сардора, подтвердите план.
2. В селекторе демонстрации переключитесь на друга и выберите «Буду».
3. Вернитесь к Сардору, измените время или место. Убедитесь, что всем нужно ответить заново.
4. Снова подтвердите участие. Проверьте «Выхожу», «Задерживаюсь» и «Прибыл».
5. От имени Сардора завершите встречу, добавьте заметку или фото, откройте историю.

Переключение между участниками доступно только для встроенной демонстрационной встречи. Кнопка **Demo** после подтверждения удаляет локальные встречи и фото и восстанавливает начальный сценарий.

## Честные ограничения beta

Backend пока отсутствует. Данные и локальная роль участника сохраняются только в текущем браузере и на текущем origin. Вкладки одного браузера получают изменения через событие `storage`.

Ссылка приглашения содержит снимок встречи во фрагменте `#invite=…`, поэтому другой браузер может открыть приглашение и присоединиться к **своей локальной копии**. Голоса и изменения между разными браузерами **не синхронизируются**. Для полной демонстрации общей встречи используйте переключатель участников Demo. При проверке гостевого приглашения новой встречи открывайте ссылку в отдельном профиле или приватном окне, чтобы сохранить роль организатора в исходном браузере.

Ссылка содержит название, описание, варианты и имена участников; отправляйте её только приглашённым. Фото и заметки воспоминаний в ссылку не входят. Доступ к ролям в этой beta — удобство интерфейса, а не серверная аутентификация.

Длинные ссылки могут превысить вместимость QR. В этом случае доступно копирование ссылки. Удаление данных сайта в браузере удаляет и встречи; облачного резервного копирования нет.

Намеренно отсутствуют: аккаунты и пароли, сервер/API, оплата, чат, AI, карты/GPS, push-уведомления и рейтинг пунктуальности.

## Основные файлы

```text
src/
  main.jsx                    # React, BrowserRouter, общий контекст
  App.jsx                     # Маршруты, навигация, сброс Demo
  context/AppContext.jsx      # Обновление данных и уведомления
  pages/
    Home.jsx                  # Предстоящие и недавняя история
    Create.jsx                # Создание встречи
    Meeting.jsx               # Голосование, план, участие и прибытие
    Join.jsx                  # Гостевое приглашение
    Memory.jsx                # Фотографии и заметка
    History.jsx               # Завершённые встречи
  components/MeetingCard.jsx   # Карточка встречи
  components/Brand.jsx         # Логотип в шапке
  services/
    storage.js                # Вся работа с localStorage, правила и роли
    calendar.js               # RFC 5545 .ics
    photos.js                 # Проверка и сжатие изображений
  utils/format.js              # Даты, состояния, число участников
  styles.css                  # Общий адаптивный дизайн
  meeting.css                 # Страницы встречи и воспоминаний
tests/storage.test.js          # Бизнес-правила и критический перенос
e2e/yavka.spec.js              # Проверки браузерного сценария
playwright.config.js           # Desktop/mobile Chromium
public/brand/yavka-logo.jpg     # Предоставленный оригинал логотипа
```

Компоненты используют API `services/storage.js`, а не обращаются к `localStorage` напрямую. `setStorageAdapter` позволяет подменить локальный адаптер в тестах. При подключении Supabase/API сохраните интерфейс сервисного слоя, замените реализацию на асинхронную и добавьте серверную проверку прав и синхронизацию; локальное переключение Demo не является моделью авторизации для production.

## Результаты проверки

Успешно выполнены `npm install`, повторная установка `npm ci`, `npm run build`, 17 сервисных тестов и 8 браузерных проверок desktop/mobile Chromium. В браузере проверен полный путь от создания и приглашения до переноса, завершения, фото и истории, включая сохранение после перезагрузки. Отдельно проверена production-сборка через `npm run preview`: прямое открытие маршрута, подтверждение плана и сохранение статуса прибытия. Адаптивность проверена на ширинах 320, 390 и 1440 px.
